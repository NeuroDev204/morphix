# Morphix GUI Spike Notes (Task 0)

## 1. System Libraries & WebKitGTK 4.1
- Package requirement: `libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev patchelf libfuse2`
- Đã cài đặt và xác minh đầy đủ:
  - `pkg-config --modversion webkit2gtk-4.1`: 2.52.6
  - `pkg-config --modversion ayatana-appindicator3-0.1`: 0.5.90
  - `pkg-config --modversion librsvg-2.0`: 2.58.0
- `cargo search tauri --limit 1`: Đã kiểm tra thành công, kết nối registry bình thường.

## 2. Tauri 2.12.4 Tray & Single Instance API
- `TrayIconBuilder`: `tauri::tray::TrayIconBuilder`
  - Constructor: `TrayIconBuilder::new()`, `TrayIconBuilder::with_id(id)`
  - Methods:
    - `.menu(&menu)`
    - `.icon(icon)`
    - `.tooltip(text)`
    - `.title(text)`
    - `.on_menu_event(handler)`
    - `.on_tray_icon_event(handler)`
    - `.build(app)`
- `tauri-plugin-single-instance` (2.5.4):
  - Signature: `pub fn init<R: Runtime, F: FnMut(&AppHandle<R>, Vec<String>, String) + Send + Sync + 'static>(f: F) -> TauriPlugin<R>`
  - Closure parameters: `(|app, args, cwd| { ... })`

## 3. interprocess 2.4.6 Local Socket API
- Socket types:
  - `interprocess::local_socket::traits::{Listener, Stream}`
  - `interprocess::local_socket::{ListenerOptions, Name, ToFsName, ToNsName}`
- Binding / Listening:
  - `ListenerOptions::new().name(name).create_sync()`
  - Trait methods on `Listener`: `accept()`, `set_nonblocking()`
- Connecting / Streaming:
  - `Stream::connect(name)`
  - Trait methods on `Stream`: `split()`, `set_recv_timeout()`, `set_send_timeout()`
- Platform naming:
  - Unix / Linux: file path socket via `ToFsName` / `GenericFilePath`
  - Windows: named pipe via `ToNsName` / `GenericNamespaced` (`\\.\pipe\...`)
